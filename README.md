# Netflix Data Analysis

## 📌 Project Overview

This project explores the Netflix titles dataset using Python,
Pandas, Seaborn and Matplotlib.

The objective is to analyze the content available on Netflix,
identify distribution patterns and extract actionable insights
from the data.

## 🎯 Objectives

- Analyze the distribution of Movies and TV Shows
- Study the evolution of Netflix content additions
- Analyze movie durations
- Analyze the number of seasons of TV Shows
- Identify the most represented categories
- Identify the most frequent directors
- Analyze recurring actors associated with specific directors

## 🛠️ Technologies

- Python
- Pandas
- Seaborn
- Matplotlib
- Jupyter Notebook

### Content distribution

Analysis of Movies vs TV Shows.

### TV Shows

number of seasons.

### Categories
